## 2. 再分发红线

- 仓库内**不得**提交：APK / AAB 安装包、解压后的 `classes*.dex`、反编译 smali / Java / Dart 还原产物、提取的原生库与私有资源、上游专有配置。
- 仓库内**不得**提交：账号 Cookie、令牌、设备标识、加密密钥、内部接口地址等敏感信息；提交前走密钥扫描。
- 不修改、不绕过上游的签名校验、登录校验、风控与内容加密保护。
- 不批量抓取、转存、传播受版权保护的影视、短剧、小说、漫画内容；平台只做入口与跳转 / 在线解析的编排。
- 聚合服务的演示数据必须是**自造虚构条目**；不得把真实作品元数据、真实播放地址或抓取结果提交为“演示数据”。
- `ResolvedSource.headers` 只放引用标识，真实令牌由服务端会话注入，不入库、不入仓库、不进日志。
- **真实接入配置不入库**：`platform/config/sources.json` 已被 `.gitignore` 排除；仓库只保留 `sources.example.json`（占位域名、默认关闭）。
- **令牌只从环境变量注入**：配置项 `auth_env` / `headers_env` 存的是变量名，不是值；日志与错误响应不得回显请求头。
- **仅访问白名单域名**：配置里的 `base_url` 主机自动进入白名单，其余域名一律拒绝；只允许 GET，禁止把适配器当通用代理或爬虫使用。

## 3. 内容与数据合规

- 仅接入公开可访问或已获授权的来源；接入前复核上游用户协议、 robots 规则与频次限制。
- 检索结果、播放 / 阅读地址的版权归原权利人所有；平台应提供内容下架 / 投诉处理通道。
- 用户个人阅读记录、书架、进度等优先存于本地或用户自己的账号体系，不做未经授权的跨源聚合画像。
- 上游接口变更、限流或下架时，适配器应能优雅降级，不强行突破限制。

## 4. 仓库卫生

`.gitignore` 默认排除：

- `*.apk`、`*.aab`、`*.dex`、`*.so` 转储目录；
- 下载的音视频、书籍、漫画等媒体文件；
- `.env`、密钥文件、日志与诊断报告；
- 真实来源配置 `/platform/config/sources.json`（含授权接口地址）；
- 构建产物与缓存目录。
