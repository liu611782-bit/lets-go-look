## 1. 目标与边界

把多个短剧 / 影视 / 小说来源聚合到同一套检索、详情与播放 / 阅读入口。平台只做**统一适配与内容编排**，不内置、不转存受版权保护的内容文件。

### 关键澄清：APK 不是 API

- APK 是安装到设备上的客户端二进制（编译后的 dex / so / 资源），本身不能被平台“当作接口调用”。
- 真正可接入的是各来源**后端公开或已授权的 HTTP 接口**；APK 在本项目中只用于识别包名、版本、技术栈与交互参考。
- 对未公开接口的来源，必须先取得授权；不得通过反编译 APK 提取私有接口、密钥或签名逻辑。

## 3. 统一领域模型（摘要）

完整定义见 [`platform/models.py`](../platform/models.py)：

- `MediaType`：`DRAMA`（短剧）/ `VIDEO`（影视）/ `NOVEL`（小说）/ `COMIC`（漫画，预留）。
- `MediaItem`：来源标识、外部 ID、标题、封面、简介、类型、作者、状态、评分等。
- `Episode` / `Chapter`：序号、标题、时长 / 字数、来源内外部 ID、更新状态。
- `ResolvedSource`：可播放 / 可阅读的地址、清晰度 / 格式、鉴权头或令牌引用、有效期。
- `SourceMeta`：适配器标识、展示名、类型支持、上游仓库、许可证、接入状态。

## 4. 适配器契约

每个来源实现同一套接口（`platform/adapters/base.py`）：

| 方法 | 职责 | 输入 | 输出 |
|---|---|---|---|
| `meta()` | 返回来源元信息与接入状态 | — | `SourceMeta` |
| `search(query, type, page)` | 按关键词检索 | 关键词、类型、分页 | `list[MediaItem]` |
| `detail(item_id)` | 取详情 | 来源内外部 ID | `MediaItem` |
| `episodes(item_id)` | 短剧 / 影视分集（可选实现） | 来源内外部 ID | `list[Episode]` |
| `chapters(item_id)` | 小说章节（可选实现） | 来源内外部 ID | `list[Chapter]` |
| `resolve(item_id, episode_id)` | 解析出可播放 / 阅读地址 | 内容 ID、分集 ID | `ResolvedSource` |

**统一约定**：

- 适配器不直接向前端暴露上游原始字段；先归一化到领域模型，再由聚合服务合并。
- 鉴权信息（Cookie / 令牌 / 设备标识）只存于服务端会话或加密配置，不写入前端日志与仓库。
- 所有上游请求走统一 HTTP 客户端：超时、重试、限流、UA / 代理策略、响应压缩。
- 解析失败、需要登录、地区受限、内容下架等情况，用统一错误码返回，不抛出上游原始堆栈。
- 适配器以异常表达状态：`PermissionError` → `SOURCE_DISABLED`，`NotImplementedError` → `SOURCE_NOT_READY`，其余 → `UPSTREAM_ERROR`。

## 6. 非功能需求

- **缓存**：检索结果、详情页短 TTL 缓存；播放地址按有效期缓存，过期重解析。
- **限流与合规**：遵守上游频次约定；不做高频批量抓取；不绕过登录、风控或加密保护。
- **可观测**：记录各来源响应耗时、成功率、错误分类；不含个人身份信息。
- **体积**：源码骨架与文档入库；APK 安装包、下载的音视频 / 书籍文件一律不进仓库（见 `.gitignore`）。
